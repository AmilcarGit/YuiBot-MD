# Fuentes incluidas

Se incluyen para que las imágenes (perfil, bienvenida, juegos, RPG, memes) se vean igual en cualquier equipo,
incluido Termux, que casi no trae fuentes del sistema.

- **Poppins** (Regular, Bold, Italic, BoldItalic) — Indian Type Foundry — licencia SIL Open Font License 1.1.
- **DejaVu Sans** (Regular, Bold) — Bitstream Vera / DejaVu fonts — licencia libre que permite redistribuirlas
  (https://dejavu-fonts.github.io/License.html). Se usa para símbolos como ✦ ▰ ⚔ ♡ y letras que Poppins no tiene.
