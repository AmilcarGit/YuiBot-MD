## 🌸 Sobre YuiBot-MD

**YuiBot-MD** es un bot de WhatsApp Multi-Device desarrollado con **Node.js** y **Baileys**.

El proyecto está comenzando y tiene como objetivo construir una base de bot **simple, modular, organizada y fácil de personalizar**.

> 🚧 **YuiBot-MD está actualmente en desarrollo.**
>
> El proyecto irá incorporando nuevos comandos, herramientas y funciones progresivamente.

## ✨ Características

- 📱 WhatsApp Multi-Device
- 🔗 Conexión mediante QR
- 💾 Persistencia de sesión
- 🔄 Reconexión automática
- 🧩 Sistema modular de comandos
- 📂 Organización mediante carpetas
- 🏷️ Soporte para aliases
- ⚙️ Prefijo configurable
- 🛠️ Fácil de modificar
- 🚀 Proyecto preparado para crecer
