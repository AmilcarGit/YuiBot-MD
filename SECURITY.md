# Política de seguridad

## Reportar una vulnerabilidad

No publiques vulnerabilidades explotables, credenciales ni tokens en Issues públicos.

Utiliza la opción **Report a vulnerability** de la pestaña Security de GitHub si está disponible para este repositorio. Si no aparece, contacta al mantenedor mediante los canales privados disponibles en su perfil de GitHub e incluye solo la información necesaria para reproducir el problema.

## Qué incluir

- Repositorio y componente afectado.
- Versión o commit afectado, si se conoce.
- Pasos mínimos para reproducir el problema.
- Impacto potencial y una posible mitigación.

## Protección de datos

Nunca subas sesiones de WhatsApp o Telegram, archivos `.env`, contraseñas, tokens de API, claves privadas ni datos personales. Si un secreto se publicó, revócalo y genera uno nuevo; borrar el archivo del último commit no invalida el secreto.
